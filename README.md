## 🛠️ Tech Stack
* **Language:** LaTeX
* **Editor:** Overleaf / VS Code (LaTeX Workshop)
* **Template:** Jake's Resume (Modified)

## 🚀 How to Build Locally
If you want to compile this resume yourself, ensure you have a TeX distribution installed (TeX Live, MacTeX, or MikTeX).

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/atharvashivari/resume.git](https://github.com/atharvashivari/resume.git)
    cd resume
    ```

2.  **Compile with pdflatex:**
    ```bash
    pdflatex main.tex
    ```
